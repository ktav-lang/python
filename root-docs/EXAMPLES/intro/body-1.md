# Examples

**Languages:** **English** · [Русский](README.ru.md) · [简体中文](README.zh.md)

Standalone scripts exercise the package end-to-end. Run `maturin develop`
first to install the local extension.

- [`basic.py`](basic.py) parses a service config and round-trips it through
  `dumps` and `loads`.

```bash
python examples/basic.py
```
