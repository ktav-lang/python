# Примеры

**Языки:** [English](README.md) · **Русский** · [简体中文](README.zh.md)

Самостоятельные скрипты проверяют пакет целиком. Сначала установите локальное
расширение командой `maturin develop`.

- [`basic.py`](basic.py) разбирает конфигурацию сервиса и проверяет обратное
  преобразование через `dumps` и `loads`.

```bash
python examples/basic.py
```

Тот же код работает и с чистым backend-ом — `from ktav import pure` и
`pure.loads(...)` — без скомпилированного расширения.
